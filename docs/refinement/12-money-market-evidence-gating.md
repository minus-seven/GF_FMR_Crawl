# 货币基金报告期与图表证据门控

## 目的

货币基金事实资料表常由 MinerU 识别出图表标题，但正文 Markdown 不包含图表数值。若此时直接把本地 Qwen 的候选值写入结果，模型可能复用同类基金模板，产生跨基金持仓、地区、流动性和 WAM/WAL 数字。

## 当前契约

- `report_date` 优先取 PDF 原文“截至 / Data as at”后的完整日期；例如 `截至2026年9月30日` 保存为 `2026-09-30`。没有日时才保存 `YYYY-MM`，入库仍转换为对应日期。
- 货币基金在最终规范化前读取原生 PDF 文本。明确标签后的 WAM 与图表数值由代码提取，覆盖模型候选。
- “久期分布”按 `<1月`、`1-<3月`、`3-<6月`、`6-<12月` 与百分比序列配对；“资产类别分布”按原文资产类别与百分比配对。
- 没有 PDF 标签锚点的模型列表/指标（前十大持仓、地区配置、银行敞口、WAL、日/周流动资产、派息）清空为未披露，不进入数据库。
- 货币基金地域图表常把标签和值拆成两列；当前没有专用配对解析器，因此即使出现“地区分布”标题，也不接受 Qwen 单项地域值，避免再次写入模板复用的 `98.5%`。
- 被清空字段的模型证据引用也清空，避免 UI 把跨模板引用展示为有效来源。

## BPJ877 原文核验结果

原生 PDF 明确披露：报告期 `2026-09-30`、加权平均届满期 `57.84天`、久期分布 `65.82/16.51/3.42/14.24%`、资产类别分布 `39.21/42.54/18.24%`。PDF 没有前十大持仓、地区配置、银行敞口、WAL 或日/周流动资产的明确字段，因此这些模型候选均不得直接采用。
