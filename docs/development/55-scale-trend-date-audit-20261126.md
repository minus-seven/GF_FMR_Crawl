# 规模趋势日期审计与修复（2026-11-26）

## 结论

“当前基金规模趋势”原来直接聚合当前发布批次的全部 `fund_scale_history` 行。月报结构化结果和 HKEX 主数据合并到同一批次时，缺少基金/报告期去重与日期契约校验，导致模型输出的事件日期或月初日期被当成规模趋势点。

## 代码契约

- `platform/api/app/importers/common.py`：结构化结果只有 `YYYY-MM` 时，按自然月月末落库；原文明确给出日时保留原日。
- `platform/api/app/services/report_type.py`：终止/清盘通知优先识别为 `supplementary`，不因免责声明中的“本月报”字样误判为月报。
- `platform/api/app/services/queries.py`：规模趋势和列表最新规模只接受自然月月末记录，并过滤未来日期。这样历史旧批次即使仍保留错误原始行，也不会进入默认 UI 口径。

## 数据处理原则

1. 原始 PDF、Markdown、模型 JSON、旧任务批次不删除，保留用于审计和质量复核。
2. 只修复当前发布批次中的错误规模行；HKEX 主数据月末值优先于结构化补充值。
3. 趋势图是“月末规模趋势”，不是事件日期/持仓到期日时间轴；非月末规模记录不参与该图。
