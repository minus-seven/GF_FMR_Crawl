## 3. 全链路回归

### 3.1 已验证链路

```text
自然语言问题
  → SQL 优先问答
  → claim/evidence 绑定（文档、报告期、页码、哈希）
  → 证据不足时拒答
  → Agent 生成计划
  → 用户拒绝不写库
  → 用户确认创建真实 job
  → 测试 job 取消并释放租约
```

真实冒烟中，单基金月报计划返回 `awaiting_confirmation`，确认后返回 `job_id`，随后取消测试任务；未确认路径没有创建任务。来源隐藏/显示语义、临时集合范围、任务目标（基金月报/半年报）在 API 契约和现有测试中保持兼容。
