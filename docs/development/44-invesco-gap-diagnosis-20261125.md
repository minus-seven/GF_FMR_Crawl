# 景顺适配器缺口诊断（2026-11-25）

## 现象

景顺页表仍有 26 个缺口，但复跑适配器没有新增链接。该结果不是适配器异常退出，而是官方当前目录与历史主数据的生命周期差异。

## 证据与分类

- `NO_FACTSHEET`：景顺黄金机遇基金详情页未返回可验证的当前月度 Factsheet。
- `NO_CURRENT_FUND`：18 个产品在景顺当前香港开放基金目录中找不到可验证的开放份额，主要是旧产品、到期基金或历史集成投资基金。
- `NO_PUBLIC_DETAIL`：7 个景顺特选退休基金产品在官方目录接口中有记录，但对应公开详情路由返回 HTTP 404，无法安全构造下载地址。

适配器使用景顺香港官方基金目录及详情页作为来源；不以全球站点、气候指标 PDF、旧版产品文件或名称相近的基金替代月报入口。这样保留缺口比写入不可复核或错误归属的链接更可靠。

## 后续动作

若业务需要补齐历史产品，应提供基金代码对应的历史月报存档或允许把“历史报告/非当前月报”作为单独来源类型；届时应新增来源状态，不应覆盖当前月报字段。
