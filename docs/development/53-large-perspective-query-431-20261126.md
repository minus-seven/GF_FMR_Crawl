# ECharts 大范围查询 431 修复（2026-11-26）

## 现象

基金数据库默认范围包含 2,504 只基金。页面会把当前范围的全部代码作为重复的
`scope_fund_codes` 查询参数发送到 `GET /api/analytics/perspectives`。URL 超过
Vite/反向代理的请求行上限后，代理直接返回空的 HTTP 431，前端只能显示：
“服务返回空响应 (431)，请确认 API 服务正在运行”。API 本身和数据库均正常。

## 修复

- 保留 GET 作为小范围兼容路径；超过 100 只基金时，Web 客户端改为向
  `POST /api/analytics/perspectives/query` 发送 JSON body。
- 新增 `PerspectiveQuery` 请求模型，支持基金代码、管理人、资产类别、报告期和来源版本，
  最多接受 10,000 个基金代码。
- GET 路径的旧固定 2,479 上限改为 10,000，避免与动态基金数量再次冲突。
- 图表计算统一复用同一个服务调用，因此规模趋势、规模分布和投资组合结构的口径不变。

## 验证

- 当前数据库 2,504 个基金代码经 POST 查询返回 HTTP 200，返回范围计数 2,471，三类视图正常。
- 通过 Vite `:5173` 代理转发 POST 查询返回 HTTP 200。
- Python API 编译通过；Web 定向测试 9 项通过，`npm run build` 通过。

若浏览器仍保留旧页面实例，请刷新页面一次，使其加载新的请求路径；已完成的任务和数据库数据不受影响。
