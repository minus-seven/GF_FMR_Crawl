# 投资组合结构图表布局适配（2026-11-26）

## 问题

投资组合结构使用饼图时，右侧纵向图例会在窄面板中与图形、长分类名称发生挤压，出现图表与图例重叠或可读性下降。

## 调整

- 保留右侧纵向图例，但将其放入独立的浅色边界区域，设置固定分栏宽度、内边距和条目间距。
- 饼图收紧并固定在左侧，避免与图例区域相互侵入；较长分类名称在图例中截断，悬浮提示保留完整名称。
- 图表卡片高度调整为 232px。
- 在中等宽度布局（不超过 1180px）时，投资组合结构卡片独占一整行，避免与其他图表并排挤压。
- 仅在存在投资组合结构数据时渲染该卡片；长分类名称仍可通过 ECharts tooltip 查看完整内容。

## 验证

在 `platform/web` 执行 `npm run build` 通过。该调整只影响前端布局，不改变投资组合结构数据、来源时间点或 API 契约。
